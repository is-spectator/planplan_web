# MVP 之后的版本

以下不阻塞 v0.1–v0.3；均未实施，也未承诺发布日期。先根据真实试用决定优先级。

## 候选 v0.4：成长反馈

用户价值：让持续记录获得可见反馈，增加回访理由。

- 迁移现有成长小屋、行动力、物品解锁、同行榜和每周卡片。
- 现有后端和 iOS 已有这些功能；Web 需要重新实现交互及图形表现。
- 周卡优先支持图片下载；设备支持时再提供系统分享。
- 明确同行榜只共享允许的昵称与汇总信息，不能泄露账单和学习明细。
- 验收：行动力和原端一致、解锁状态保留、加入/退出同行榜正确、导出图片可用、分享范围明确。

## 后续独立工作包

| 能力 | 用户价值 | 开始前要解决的问题 |
| --- | --- | --- |
| 语音输入 | 减少手机输入成本 | 浏览器兼容性、是否上传音频、服务告知；不能沿用 iOS 本机识别承诺 |
| 完整离线/PWA | 离线查看、持久草稿、安装入口 | 明确本机留存、用户选择、过期清理、队列多标签协调与数据恢复 |
| 每设备会话 | 网页退出不影响手机 | 新会话模型、单设备撤销、密码重置后的会话策略及 iOS 兼容 |
| 昵称头像同步 | 两端展示一致 | 当前资料仅 iOS 本机保存，需服务端资料 API 与迁移策略 |
| 开放注册 | 更多人自行加入 | 取消白名单前重做成本、限流、邮件容量、滥用控制和支持能力评估 |
| 实时推送/流式交互 | 更及时的变化提示 | 新协议与断线恢复；流式文案不等于事务已提交 |

多币种、收入与资产、银行同步、图片识别、任意任务清单、自动提醒和团队协作属于新的产品范围。需要独立需求与数据模型评估，不作为 Web MVP 的隐含承诺。
